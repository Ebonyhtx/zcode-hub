# 故障排查 / Troubleshooting

## 找不到 ZCode 客户端

- 确认已安装 Windows 版 ZCode，并至少启动过一次。
- 设置 → 客户端路径，选择 `ZCode.exe`；留空表示自动探测。
- 如果安装在自定义目录，自动探测会先查运行中的进程；先启动一次客户端。
- 路径填错不会静默回退：设置保存时会校验文件是否存在。

## 额度拉取失败

| 提示 | 含义 | 处理 |
|---|---|---|
| 登录已过期 | 该账号 token 失效 | 切换该账号后在 ZCode 里重新登录，再保存 |
| 请求过于频繁 | 接口限流 | 等待 1 分钟或降低自动检测频率 |
| 服务端暂时不可用 | 5xx/网关错误 | 稍后自动重试 |
| 网络不可用 | 本机网络/DNS/代理 | 检查网络后点刷新 |
| 账号缺少设备标识 | 旧存档没有 deviceMid | 切换该账号一次，Hub 会自动补齐 |

## 切换失败

- “无法确认 ZCode 是否在运行”：进程探测失败时 Hub 会拒绝切换，避免在
  客户端运行时改凭据。手动退出 ZCode（包括托盘）后重试。
- “无法关闭 ZCode”：客户端可能仍在托盘。右键托盘退出，或任务管理器结束。
- “替换凭据失败且恢复也失败”：不要重复切换；用「备份 / 导入」恢复，
  或重新登录 ZCode。Hub 会把损坏的 live 文件保留为
  `credentials.json.corrupt`，并保留切换前备份。
- 目标账号显示“登录已过期”：切换后需要在 ZCode 里重新登录该账号。

## 存档无法读取

- 提示“存档无法读取/无法解密”时，账号卡会显示具体原因，不会静默消失。
- 常见原因：换了 Windows 用户/机器、`snapkey` 被安全软件拦截、磁盘损坏。
- 不要删除 `%APPDATA%\zcode-hub\snapkey`；删除会让所有存档永久不可解。
- 有 `.zhb` 备份时，用导入恢复（跨机请用口令包，不要直接拷 profiles）。
- 本机自动备份在 `%APPDATA%\zcode-hub\backups\`，保留最近 7 份。

## 领取验证码打不开 / 一直等待

- 验证码页由本机回环 HTTP 服务提供，需要系统浏览器能访问 `127.0.0.1`。
- 如果浏览器/安全软件拦截本地回环，尝试临时关闭拦截或换默认浏览器。
- 关闭浏览器后，可在应用内点「重新打开验证页」，不必重新发起领取。
- 等待超时会提示重试；领取状态在后台进行时不要重复点击。

## 托盘图标/通知

- 关闭窗口默认最小化到托盘；首次会弹一次说明通知。
- 托盘菜单：显示 / 立即检测福利 / 快速切换 / 打开 ZCode / 退出。
- 全局快捷键 `Ctrl+Shift+Z` 呼出或隐藏主窗口；被其它程序占用时静默降级。
- 通知开关在顶部“通知”和设置 → 额度提醒/新版本提醒里分别控制。
- Windows 通知需要系统“通知和操作”里允许 ZCode Hub。

## 备份导入失败

- “口令错误或文件损坏”：确认口令；`.zhb` 口令无法找回。
- “不是 ZCode Hub 备份文件”：确认文件以 `ZHB1:` 开头。
- 预览里标“重复”的账号会被跳过；标“需重登”的账号导入后要重新登录。
- 跨大版本导入仍兼容 v1/v2 格式；v1 的字段可能需要在目标机重登。

## 需要进一步诊断

设置 → 导出诊断报告，生成脱敏 JSON（无 token/邮箱/展示名），附在
Issue 里即可。启动耗时在 `%APPDATA%\zcode-hub\startup.log`；审计日志在
同目录 `audit.jsonl`（账号键已哈希）。

## 重置数据（谨慎）

先退出 Hub 和 ZCode，并导出 `.zhb` 备份。删除 `%APPDATA%\zcode-hub\`
会清空账号库、设置、审计、自动备份；`snapkey` 一并删除后旧快照不可恢复。
如需保留账号库只重置设置，删除 `hub-config.json` 即可。
