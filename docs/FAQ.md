# 常见问题 / FAQ

## 这是官方工具吗？

不是。ZCode Hub 是第三方的本地多账号管理工具，与 ZCode / Z.AI / BigModel
官方无关。它只读写本机已有的客户端文件，不修改官方客户端的加密方式。

## 它会自动领取福利吗？

不会。Hub 只负责检测与展示；领取需要你在系统浏览器里手动完成验证码。
项目明确禁止自动/定时领取、验证码绕过自动化和遥测造假。

## 我的账号数据存在哪里？

- 账号快照：`%APPDATA%\zcode-hub\profiles\<账号>\credentials.snap`
  （AES-256-GCM 整包，主密钥经 Windows DPAPI 绑定当前用户和机器）
- 设置/福利/额度缓存/审计/备份：同在 `%APPDATA%\zcode-hub\`
- 当前登录：`%USERPROFILE%\.zcode\v2\credentials.json`（官方客户端格式）

设置 → 打开 Hub 数据可以直接定位。

## 换电脑怎么迁移？

用「备份 / 导入」导出口令加密的 `.zhb`，在新机器导入并输入同一口令。
导入前会显示预览（新增/重复/需重登）。DPAPI 快照只能在原机器解密，
所以不要直接拷 `profiles/` 目录换机。

## 误删账号或数据坏了能回滚吗？

能。Hub 每天在本机留一份备份（`%APPDATA%\zcode-hub\backups\`，保留 7 份）。
设置 →「恢复备份」会列出每份备份的时间、账号数和完整性，可指定恢复到其中一份；
数量与清单不符的备份会标「不完整」并拒绝恢复，恢复前还会自动再做一份安全备份，
失败自动回滚。注意它只是**本机**恢复点，换机器仍要用 `.zhb`。

## 出问题时怎么提供线索？

设置 → 导出诊断报告，生成脱敏 JSON（不含 token、邮箱、展示名）。
崩溃和界面脚本错误另外记录在 `%APPDATA%\zcode-hub\crash.log`，
两者都可以直接附在 Issue 里。

## 为什么安装时 Windows 提示“未知发布者”？

当前安装包没有购买 Authenticode 代码签名证书，只对自动更新做了
minisign 签名。SmartScreen 提示属于预期；校验下载来源和 SHA-256 后
再运行。后续若购买证书会消除该提示。

## 热切换后左下角账号名没变？

热切换只替换凭据文件，客户端界面里的账号名来自本地缓存，需要重启
ZCode 才会更新；套餐/额度已按新账号生效。设置里可以关闭热切换，
改用会重启客户端的冷切换。

## 安全模式是什么？

当客户端文件格式变化或探测到异常时，安全模式只合并账号身份字段
（token、active_provider、目标家族的 access/refresh/user_info），
保留客户端未知字段，写入后回读校验，失败恢复原文件。它比整文件
替换更保守，但可能不适用于所有版本。

## 为什么额度偶尔显示“服务端暂时不可用”？

接口可能限流或临时故障。Hub 对成功响应缓存 90 秒、失败 20 秒，
自动检测失败会按 1→2→5→10 分钟退避；点击刷新可以强制重试。

## 支持 macOS / Linux 吗？

目前只支持 Windows 10/11 x64。平台抽象层已就绪，真实移植需要
macOS 签名/公证账号和真实需求信号。

## 数据会被上传吗？

不会上传账号库或审计日志。联网只发生在：读取官方额度/福利接口、
OAuth 登录、检查 GitHub Release 更新。诊断报告由你手动导出。
